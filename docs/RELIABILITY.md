# 안정성

자동매매 안정성은 전략 성과 이전의 기본 조건입니다. 시스템은 잘못된 중복 주문, 상태 불일치, 조용한 실패를 피해야 합니다.

## 런타임 기준

- 전략은 봉 마감 기준으로 실행합니다.
- 같은 봉은 한 번만 처리합니다.
- 서버 재시작 시 MT5 열린 포지션과 전략 상태를 대조합니다.
- MT5 연결이 끊기면 신규 주문을 중단하고 UI와 로그에 표시합니다.
- 주문 요청, 주문 성공, 주문 실패, SL 수정, 청산은 모두 구조화된 로그로 남깁니다.

## 장애 대응

- 주문 실패 시 전략 상태를 임의로 진입 완료로 바꾸지 않습니다.
- 포지션 청산 실패 시 반대 방향 신규 진입을 막습니다.
- SL 수정 실패 시 재시도 정책과 알림을 적용합니다.
- MT5 포지션과 서버 상태가 다르면 서버 상태를 보류 상태로 두고 수동 확인을 요구합니다.

## 관측 지표

- 마지막 처리 봉 시간
- 마지막 신호 시간
- 주문 성공률과 실패 사유
- 현재 스프레드
- 전략별 포지션 수
- 일간 손익과 일간 손실 한도 사용률

## 실거래 전 체크리스트

- 지표 계산 테스트 통과
- 상태 머신 테스트 통과
- dry_run 로그 확인
- 데모 계좌 주문 테스트 완료
- 최대 손실 제한 설정
- 비상 중지 동작 확인
