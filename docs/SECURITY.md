# 보안

자동매매 시스템의 보안은 계좌 접근, 주문 권한, 비밀값 관리, 실거래 전환 통제에 집중합니다.

## 계정과 비밀값

- MT5 로그인, 비밀번호, 서버 정보는 소스 코드에 저장하지 않습니다.
- 비밀값은 환경 변수 또는 별도 보안 저장소를 통해 주입합니다.
- 로그에는 계좌 비밀번호, 토큰, 민감한 연결 정보를 남기지 않습니다.

## 주문 권한

- 실거래 주문은 명시적으로 활성화된 전략 인스턴스만 보낼 수 있습니다.
- UI 요청만으로 즉시 live 모드가 켜지면 안 됩니다.
- 전략별 magic number와 comment를 사용해 수동 주문과 자동매매 주문을 구분합니다.
- 수동 청산과 자동 청산이 충돌하지 않도록 열린 포지션을 항상 재조회합니다.

## 리스크 경계

- 최대 lot
- 심볼별 허용 여부
- 일간 최대 손실
- 연속 손실 제한
- 최대 동시 포지션 수
- 스프레드 상한

이 경계 중 하나라도 실패하면 신규 주문을 막습니다.

## 리뷰 기준

실거래 주문, 포지션 청산, SL 수정, 비밀값 로딩, live 모드 전환을 바꾸는 코드는 보안 리뷰 대상입니다.
