# 프론트엔드

프론트엔드는 자동매매 상태를 이해하고 제어하는 표면입니다. 주문 판단은 UI가 아니라 `Service`와 `Runtime`에서 수행합니다.

## 전략 화면 원칙

- Red-Green 전략은 메인 전략으로 가장 먼저 노출합니다.
- 사용자는 현재 모드가 `dry_run`, `demo`, `live` 중 무엇인지 즉시 알 수 있어야 합니다.
- 시작/중지, 실거래 활성화, 파라미터 변경은 명확한 상태 피드백을 줘야 합니다.
- 마지막 처리 봉, 마지막 신호, 현재 포지션, SL, TP1, Trail 상태를 함께 보여줍니다.
- 신호가 없는 경우에도 “왜 진입하지 않았는지” 확인할 수 있는 조건 상태를 보여줍니다.

## 금지 사항

- UI에서 직접 MT5 주문 API를 호출하지 않습니다.
- 차트 색상만으로 진입/청산 상태를 표현하지 않습니다.
- 실거래 활성화 버튼을 기본으로 켜진 상태로 두지 않습니다.
- 전략 상태와 계좌 상태를 분리해서 사용자가 오해하게 만들지 않습니다.

## 필요한 화면 요소

- 전략 상태 배지
- 모드 선택 또는 토글
- 심볼과 타임프레임 표시
- 파라미터 읽기 전용 요약
- 포지션 상태 패널
- 최근 신호와 최근 주문 로그
- 실거래 전 확인 모달
