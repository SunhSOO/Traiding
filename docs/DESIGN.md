# 디자인

SUPERRICH의 디자인은 자동매매 상태를 빠르게 이해하고, 위험한 행동을 신중하게 실행하도록 돕는 데 집중합니다.

## 화면 원칙

- 실거래 상태, 연결 상태, 포지션 상태는 항상 눈에 띄게 표시합니다.
- 전략 카드에는 마지막 신호, 현재 조건 충족 여부, SL, TP1, Trail 상태를 함께 보여줍니다.
- 손익보다 먼저 리스크 상태를 볼 수 있어야 합니다.
- 실거래 활성화, 포지션 청산, 전략 중지는 명확한 확인 피드백을 제공합니다.

## Red-Green 전략 표현

- 상승 조건은 초록 계열, 하락 조건은 빨강 계열을 사용하되 화면 전체를 한 색으로 몰지 않습니다.
- TP1은 파랑, SL은 빨강, Trail은 노랑 계열로 구분합니다.
- 색상만으로 상태를 전달하지 않고, 텍스트와 수치도 함께 표시합니다.

## 피해야 할 표현

- 전략을 마케팅 페이지처럼 설명하는 첫 화면
- 실제 주문 상태와 전략 계산 상태를 분리해 보여주는 화면
- 사용자가 live 모드를 실수로 켤 수 있는 배치
- 차트 장식이 핵심 리스크 정보를 가리는 구성
