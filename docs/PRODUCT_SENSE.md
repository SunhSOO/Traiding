# 제품 감각

SUPERRICH의 자동매매 제품 원칙은 “빠른 실행”보다 “이해 가능한 실행”을 우선합니다.

## 핵심 원칙

- 사용자는 전략이 어떤 조건으로 진입했는지 확인할 수 있어야 합니다.
- 실거래는 항상 의도적으로 켜야 하며, 기본은 안전한 모드여야 합니다.
- 손실 제한과 주문 실패 처리는 기능이 아니라 제품의 핵심 신뢰 요소입니다.
- Pine Script의 시각적 신호는 참고 자료이고, 서버의 상태 머신이 실제 권위 소스입니다.
- 자동매매가 멈췄을 때 사용자는 멈춘 이유와 다음 조치를 알 수 있어야 합니다.

## 메인 사용자 흐름

1. 사용자가 MT5 연결 상태를 확인합니다.
2. 사용자가 Red-Green 전략의 심볼, 타임프레임, 리스크 설정을 확인합니다.
3. 사용자가 dry_run 또는 demo 모드로 전략을 실행합니다.
4. 시스템이 신호, 주문 의도, 포지션 상태를 기록합니다.
5. 사용자가 검증 결과를 확인한 뒤 live 모드를 명시적으로 켭니다.

## 성공 기준

- 전략이 진입하지 않아도 사용자는 이유를 이해할 수 있습니다.
- 포지션이 열려 있으면 현재 SL, TP1, Trail 상태가 보입니다.
- 주문 실패가 발생하면 원인과 복구 상태가 표시됩니다.
